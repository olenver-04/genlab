# Genetic Garden — Генетикалық бақ 🌸

Интерактивті Streamlit-сайт: әр оқушы сабақтан алған бір маңызды ойды жібереді, ал проектордағы ортақ баққа оның атымен гүл қосылады.

## Беттер
- `/?view=wall` немесе `/` — проектордағы гүлдер бағы (әр 3 секунд сайын жаңарады)
- `/?view=student` — оқушының жауап жіберу формасы
- `/?view=admin` — мұғалімнің басқару панелі (пароль қажет)

## Бастау

```bash
pip install -r requirements.txt
streamlit run app.py
```

Streamlit Cloud-та бұрынғы `genlab` репозиторийіне `app.py`, `requirements.txt`, `README.md` файлдарын ауыстырсаңыз, бұрынғы Streamlit хостинг пен URL өзгермейді (негізгі файл `app.py` болса).

Мұғалім панелі үшін Streamlit Cloud → App settings → Secrets ішіне мынаны қосыңыз:

```toml
ADMIN_PASSWORD = "өзіңіздің-күшті-құпиясөзіңіз"
```

**Ескерту:** `genetics_lab.db` жергілікті SQLite файлы Streamlit Cloud-та тұрақты қойма емес. App рестарт, қайта деплой немесе реплика ауысқанда деректер жойылуы мүмкін. Сабақ соңында CSV экспортын алыңыз. Ұзақ мерзімді сақтау үшін ортақ сыртқы дерекқор (мысалы, Supabase Postgres) қажет. Бұл нұсқа бір процестегі сабаққа арналған.

Тек бір атпен бір гүл енгізіледі (тек толық жауапты мұғалім өшіріп қайта жіберуге мүмкіндік береді). Бірдей есімдері бар студенттер толық аты-жөнін қолданғаны жөн.

Гүлдердің бояуы үш тақырыпқа сәйкес келеді, пішін айырмашылықтары – сәндік визуал, нақты генетикалық фенотипті есептеу емес.
