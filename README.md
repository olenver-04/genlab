# Генетикалық зертхана

Интерактивті Streamlit-сайт сабақтағы рефлексия үшін.

## Идея
Оқушылар жас генетик рөлінде 3 ғылыми секцияның бірін таңдайды:
- 🧬 Хромосомалық теория
- 🧪 Аллельді гендер
- 🔬 Аллельді емес гендер

Олар бір маңызды факт немесе қысқа ой жібереді, ал проектордағы виртуалды зертхананың сәйкес модулі жарықтанып, ішінде жаңа «ашылым» пайда болады.

## Беттер
- Негізгі экран: `/`
- Оқушы парағы: `/?view=student`
- Мұғалім панелі: `/?view=admin`

## Орнату
```bash
pip install -r requirements.txt
streamlit run app.py
```
